私の経験では、.graphqlファイルを書くよりも、コード内に直接GraphQLを記述する方が優れています。

JS/TSプロジェクトで.graphqlファイルを取り込むにはたくさんの依頼ツールが必要であり、エディタでの自動補完も通常は機能しません。代わりに、文字列として直接GraphQLを記述する方が効率的です。
例：
```tsx
export const allFilmsWithVariablesQuery = graphql(/* GraphQL */ `
  query allFilmsWithVariablesQuery($first: Int!) {
    allFilms(first: $first) {
      edges {
        node {
          ...FilmItem
        }
      }
    }
  }
`);

function App() {
  // `data`は型付けされています！
  const [{ data }] = useQuery({
    query: allFilmsWithVariablesQuery,
    variables: { first: 10 },
  });
  return (
    <div className="App">
      {data && (
        <ul>
          {data.allFilms?.edges?.map(
            (e, i) => e?.node && <Film film={e?.node} key={`film-${i}`} />
          )}
        </ul>
      )}
    </div>
  );
}
```

この方法なら、設定の手間が減り、エディタのサポートも活用しやすくなります。
